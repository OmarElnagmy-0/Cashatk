# Cashatk

**Cashatk** is a simple, local-first Android application for tracking personal daily expenses. All user data, categories, and transactions are stored locally on the device without requiring any internet connection or cloud account.

## Phase 1 Screens

1. **Splash Screen** – Displays the Cashatk brand logo on launch before routing the user.
2. **Onboarding (Welcome)** – Introduces the app (*"Spend Smarter, Save More"*) with a Get Started button.
3. **Onboarding (User Name)** – Prompts the user for their First Name and Last Name for local personalization.
4. **Home** – Greets the user, displays Total Expenses, and lists recent Transactions History.
5. **Add Expense** – Allows logging a new expense by selecting a category, adding a description, entering an amount, and picking a date.
6. **Profile** – Lets the user upload a profile picture and access **Categories** (add, edit, and delete categories), **Login and Security** (6-digit local PIN), and **Data & Privacy** (local storage information).

## Phase 2 Screens

1. **Statistics** – Visualizes spending trends over Day, Week, Month, and Year alongside Top Spending breakdowns.
2. **Transaction Details** – Displays full receipt-style details (category, description, amount, date, and time) for any selected transaction.
3. **Wallet** – Provides an overview of total expenses and the complete list of all recorded transactions.
